# Контекст проекта для агента

## Команды
- Всё запускается из `app/`: `npm start` (сервер на `PORT`, по умолчанию 3000), `npm test`.
- Ссылка на панель мастера: `npm run create-master -- "Имя"`.
- Нужен Node.js ≥ 22.6: TypeScript запускается флагом `--experimental-strip-types` без сборки — не добавляй `tsc`, `ts-node`, сборщики.

## Запреты
- Нет внешних npm-зависимостей: только встроенные модули `node:*`. Новая зависимость — решение пользователя.
- В TypeScript только стираемые типы: без `enum`, `namespace`, параметров-свойств в конструкторах. Импорты — с расширением `.ts`.
- `data/*.sqlite` не коммитится.

## Отличия от умолчаний
- База — встроенный `node:sqlite` (синхронный API `DatabaseSync`), а не ORM.
- HTML собирается функциями в `src/views.ts`; любой пользовательский текст — через `esc()`.
