# S1.1: Ходячий скелет — окно занято по ссылке

## Цель
Мастер отмечает освободившееся окно, копирует готовое сообщение со ссылкой, клиент по ссылке занимает окно, мастер видит имя и телефон клиента.

## Критерии приёмки
- **AC1** Дано мастер с личной ссылкой на панель, когда он заполняет дату, время и услугу и нажимает «Сохранить окно», тогда видит готовое сообщение со ссылкой на окно и кнопку «Скопировать сообщение».
- **AC2** Дано открытое окно, когда клиент открывает ссылку, тогда видит услугу, дату и время в поясе мастера и кнопку «Занять окно».
- **AC3** Дано открытое окно, когда клиент вводит имя и телефон и нажимает «Занять окно», тогда видит «Окно ваше», а в панели мастера окно помечено занятым с именем и телефоном.
- **AC4** Дано весь путь выше, когда он пройден, тогда отправлены события `slot_released`, `offer_opened`, `slot_filled` (и `offer_copied` при копировании) без имени и телефона в свойствах.

## План
- **Стек** (трек M, `fs-plan` не запускали; уровень пользователя — средний): Node.js 22 без внешних зависимостей — `node:http`, `node:sqlite`, `node:test`, TypeScript через `--experimental-strip-types`; HTML рендерится на сервере, JavaScript только для копирования. Почему: ноль установки, одна команда запуска и тестов, всё читаемо. Кандидат пресета starter — см. `docs/analysis/h-001-run.md` в репо FlashStart.
- Подход: панель мастера по секретной ссылке `/m/<token>`, страница окна `/s/<id>`, SQLite-файл, события пишутся в таблицу `events` и в журнал.
- Всегда: телефон клиента — только в панели мастера; HTML экранируется; время хранится в UTC, показывается в Europe/Moscow.
- Никогда: регистрация, рассылки, оплата (см. «Не делаем» в spec).
