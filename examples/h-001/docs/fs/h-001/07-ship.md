# Выпуск: Окно — сухой прогон

> Синтетический пример. Аккаунты не создавались, деплой не выполнялся: гейт «URL открывается» пропущен и записан в `.fs/state.yaml`.

## Профиль
- Страна клиентов: Россия (Казань). Оплата хостинга: российская карта. Профиль: **РФ**.
- Уровень пользователя: средний.
- Что выкладываем: приложение после эпика E1 (путь до Aha). Тип: сервер + база (файл SQLite).

## Хостинг
| Вариант | Цена на старте | Где данные | Сложность | Решение |
|---|---|---|---|---|
| A. Платформа приложений российского облака с деплоем из git и **постоянным диском** | низкая, по потреблению | РФ | низкая | выбран: деплой из git, диск для SQLite, данные клиентов в РФ |
| B. Виртуальный сервер в РФ | фиксированная, низкая | РФ | средняя: обновления, бэкапы, HTTPS настраивать самому | отвергнут для первой проверки |

Критичное условие: **постоянный диск**. На платформах с одноразовым диском файл SQLite пропадает при каждом деплое — тогда нужна управляемая база, а это смена стека. Конкретный провайдер не выбран: список провайдеров в `hosting.md` пока в бэклоге.
