# Спецификация: Окно

> Синтетический пример.

## Зачем
- Job и критерии: J1 «заполнить окно после отмены до его начала»; SC1.1 (≤ 30 мин), SC1.2 (≤ 2 мин на отправку).
- Билд проверяет **A3**: мастера пользуются сами. Продолжаем, если ≥ 3 из 5 мастеров отправили ≥ 2 ссылки сами до 2026-11-02.

## Флоу по цепочке шагов
| # | Шаг | Решение | Что делает продукт | FR | Aha |
|---|---|---|---|---|---|
| 1 | Клиент отменил запись | клиенту | — | | |
| 2 | Вспомнить, кому предложить | убираем | лист ожидания = чат мастера, продукт не хранит клиентов | | |
| 3 | Написать всем | продукт делает | форма из 3 полей → готовое сообщение со ссылкой, копирование одним нажатием | FR1, FR2 | |
| 4 | Решить, кому отдать | продукт делает | первый, кто нажал «Занять», получает окно; остальные видят «уже занято» | FR3 | |
| 5 | Узнать, что окно занято | продукт делает | панель показывает имя и телефон клиента | FR4 | ★ |

Шагов мастера до Aha: 3 (заполнить форму → скопировать → вставить в чат).

## Функциональные требования
| ID | Продукт должен…, чтобы… | SC | Приоритет |
|---|---|---|---|
| FR1 | принимать окно из трёх полей (дата, время, услуга), чтобы мастер отмечал отмену за минуту | SC1.2 | must |
| FR2 | сразу показывать готовое сообщение со ссылкой и копировать его одним нажатием, чтобы не сочинять текст | SC1.2 | must |
| FR3 | отдавать окно первому клиенту, нажавшему «Занять», и показывать остальным «уже занято», чтобы мастеру не отказывать вручную | SC1.1 | must |
| FR4 | показывать мастеру, занято ли окно и кем (имя, телефон), чтобы он сразу подтвердил запись | SC1.1 | must |
| FR5 | показывать список окон мастера за неделю со статусами, чтобы видеть, сколько удалось спасти | SC1.1 | should |

## Граничные случаи
| Случай | Ожидаемое поведение |
|---|---|
| Двое нажали «Занять» одновременно | окно получает один, второй видит «уже занято» |
| Ссылку открыли после начала окна | «Окно уже прошло», кнопки нет |
| Окно занято, ссылку открыли позже | «Уже заняли», без формы |
| Пустое имя или телефон | ошибка у поля, введённое сохранено |
| Неизвестная ссылка окна | страница «окно не найдено» без раскрытия чужих данных |
| Чужая панель мастера | без верного личного токена — 404 |
| Мастер в одном поясе, клиент в другом | время показываем в поясе мастера (Europe/Moscow) с пометкой |

## Ограничения
- Всегда: телефон клиента видит только мастер; персональные данные не попадают в события; время — Europe/Moscow.

## Не делаем
| Что | Почему / когда вернёмся |
|---|---|
| Регистрация мастеров | ссылку-панель выдаём вручную, пока 5 мастеров |
| Автоматическая рассылка в мессенджеры | A4 выкинуто: мастер вставляет ссылку сам |
| Оплата и предоплата | после A3 |
| Полное расписание | не нужно для Job J1 |
