## Что выкинуть
- **A4 (выкинуто):** «нужна автоматическая рассылка в мессенджеры». Заменили: мастер сам отправляет одну ссылку в свой чат. Убирает интеграции с мессенджерами целиком.
- Регистрация мастеров: выдаём личную ссылку-панель вручную.

## Тест для топ-1
История: A1 подтвердили разговорами, A2 — ручной рассылкой (`03-test.md`). Главное открытое теперь A3.

- Допущение: A3
- Формат: прототип — панель мастера + страница окна для клиента
- Kill-порог: меньше 3 из 5 мастеров отправили сами хотя бы 2 ссылки до 2026-11-02
- Стоимость: 2–3 дня разработки + 2 недели наблюдения

## Можно ли проверить без кода?
Нет: A3 проверяет, будет ли мастер делать это **сам**. Ручная рассылка (как в A2) делала работу за мастера и ответа не даёт.
