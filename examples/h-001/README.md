# Эталонный прогон h-001 (синтетический)

Пример продуктового репозитория, прошедшего FlashStart по треку M: frame → rat → test → spec → build (+design) → ship. Гипотеза выдуманная, люди и числа в тестах — синтетические. Код в `app/` — настоящий: запускается, тесты проходят, интерфейс проверен детектором Impeccable.

| Что | Где |
|---|---|
| Артефакты гипотезы | `docs/fs/h-001/` |
| Контекст продукта и дизайн-система | `PRODUCT.md`, `DESIGN.md` |
| Состояние | `.fs/state.yaml` |
| Прототип | `app/` (`npm start`, `npm test`) |

Проверка трассировки из корня FlashStart:

```
python3 scripts/trace-check.py examples/h-001/docs/fs
```
