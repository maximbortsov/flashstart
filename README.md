# FlashStart

Фреймворк скиллов для Claude Code: проводит продуктовую гипотезу от Job клиента до работающего интерфейса и как можно раньше убивает слабые идеи.

> Статус: ранняя разработка. Скиллы написаны, эталонный прогон — `examples/h-001` (итоги — `docs/analysis/h-001-run.md`).

## Зачем

Соло-фаундер или технический продакт обычно начинает с кода. FlashStart заставляет начать с вопроса «какой Job мы делаем и что должно оказаться правдой», записать kill-критерий и проверить самое опасное допущение самым дешёвым способом. Код — только если без него проверить нельзя.

## Треки

| Трек | Когда | Шаги |
|---|---|---|
| S — без кода | риск проверяется ручной услугой, опросом, лендингом | frame → rat → test → learn |
| M — малый билд | прототип, 1–3 эпика, стек очевиден | frame → rat → spec → build (+design) → ship → learn |
| L — полный билд | интеграции, данные, сложная архитектура | frame → rat → spec → plan → build (+design) → ship → learn |

## Скиллы

| Скилл | Что делает |
|---|---|
| `fs` | статус гипотезы, долг непроверенного, следующий шаг |
| `fs-frame` | идея → Job, критерии успеха, цепочка шагов, Aha Moment, риски |
| `fs-rat` | допущения, самый дешёвый тест, порог, выбор трека |
| `fs-test` | проверка без кода: план, тексты, журнал |
| `fs-spec` | требования, события аналитики, `PRODUCT.md`, истории (трек M) |
| `fs-plan` | стек, архитектурные решения, эпики и истории (трек L) |
| `fs-build` | одна история за сессию: план, тесты, код, ревью |
| `fs-design` | экран из контекста продукта, чек-лист и детектор Impeccable |
| `fs-ship` | выкладка, домен, секреты, проверка событий, чек-лист релиза |
| `fs-learn` | факт против порога → continue / pivot / kill |

## Установка

Нужны git и Python 3.10+; для стека starter и детектора интерфейса — Node.js 22.6+.

Из папки своего продуктового репозитория — одна команда:

```bash
git clone https://github.com/maximbortsov/flashstart.git ~/.flashstart && python3 ~/.flashstart/install.py
```

Windows (PowerShell):

```powershell
git clone https://github.com/maximbortsov/flashstart.git $HOME\.flashstart; py $HOME\.flashstart\install.py
```

Установщик кладёт скиллы в `.claude/skills/` проекта, а `trace-check.py` — в `scripts/`. Другие скиллы и файлы не трогает.

| Задача | Команда |
|---|---|
| Поставить в другой проект | `python3 ~/.flashstart/install.py путь/к/проекту` |
| Для всех проектов сразу | `python3 ~/.flashstart/install.py --global` |
| Обновить | `python3 ~/.flashstart/install.py --update` |
| Удалить из проекта | `python3 ~/.flashstart/install.py --uninstall` |
| Посмотреть, что будет сделано | добавить `--dry-run` |

Репозиторий пока приватный: клонирование сработает, если у вас есть доступ к нему на GitHub.
