# Предрелизный чек-лист

Отмечай каждый пункт: **да / нет / отложено (причина)**. Отложенное записывается в `07-ship.md`.

## Открывается

- [ ] URL открывается по HTTPS с телефона и с компьютера.
- [ ] `http://` переадресует на `https://`.
- [ ] Путь до Aha проходится целиком на реальном хостинге, а не только локально.
- [ ] Страницы «не найдено» и «ошибка сервера» показывают понятный текст и путь назад.
- [ ] Время загрузки первой страницы на мобильной сети приемлемое (ориентир — до 3 секунд).

## Измеряется

- [ ] Каждое событие EV приходит с нужными свойствами.
- [ ] Свои визиты исключены или помечены.
- [ ] Записана дата, когда смотреть результаты (kill / continue).

## Персональные данные

- [ ] Записано, какие данные собираем (имя, телефон, email, оплата) и зачем — только нужное для Job.
- [ ] Есть согласие на обработку и понятная политика конфиденциальности на языке клиента.
- [ ] Данные хранятся там, где это разрешено законом страны клиентов; при сомнениях — вопрос юристу до запуска с реальными людьми.
- [ ] Персональные данные не уходят в аналитику и логи.
- [ ] Понятно, как удалить данные человека по его просьбе.

## Бэкапы и откат

- [ ] Автоматические бэкапы базы включены.
- [ ] Восстановление из бэкапа проверено хотя бы один раз (на копии).
- [ ] Известно, как откатиться на предыдущую версию, — записана команда или кнопка.

## Безопасность и гигиена

- [ ] Секреты только в переменных окружения; `.env` в `.gitignore`; в истории git ключей нет.
- [ ] Служебные папки инструментов (например, `.impeccable/questions/`, `.impeccable/mocks/`, `.impeccable/build/`) не в репозитории.
- [ ] Вход и чужие данные: прямая ссылка на чужой объект не открывает его.
- [ ] Зависимости без известных критических уязвимостей (встроенная проверка менеджера пакетов).

## Ошибки и обратная связь

- [ ] Ошибки сервера видны в логах хостинга; пользователь знает, где их смотреть.
- [ ] У клиента есть способ написать о проблеме (почта, мессенджер, форма).
- [ ] Первые 5–10 человек, которым отправим ссылку, — из сегмента во frame, а не друзья.
