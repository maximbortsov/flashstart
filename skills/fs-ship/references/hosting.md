# Выбор хостинга — общий алгоритм

> Список конкретных провайдеров для профилей РФ и зарубеж — в бэклоге (FRAMEWORK §9). Пока скилл выбирает по критериям ниже и предлагает варианты, которые им соответствуют, с оговоркой проверить актуальные условия на сайте провайдера.

## Шаг 1. Отсечь неподходящее

Вариант отпадает, если не выполнено хоть одно:

| Критерий | Вопрос |
|---|---|
| **Оплата** | Принимает ли сервис способ оплаты пользователя? Есть ли бесплатный тариф, которого хватит на тест? |
| **Данные клиентов** | Можно ли хранить персональные данные клиентов этой страны там, где сервис держит серверы? (Для клиентов из РФ закон требует хранить их данные на серверах в России — уточнить у юриста перед релизом с реальными данными.) |
| **Доступность** | Открывается ли сайт у клиентов в их стране без проблем? |
| **Тип проекта** | Поддерживает ли сервис то, что нужно: статику, сервер, базу, постоянный процесс, расписание? |

## Шаг 2. Сравнить оставшиеся

| Критерий | Что лучше для первой проверки гипотезы |
|---|---|
| Сложность для уровня пользователя | деплой из git или одной командой; понятная панель |
| Цена на старте | бесплатно или копейки, пока трафик маленький; понятно, когда начнут списывать |
| База данных | управляемая, с автоматическими бэкапами и восстановлением в пару кликов |
| HTTPS и домен | сертификат выдаётся автоматически |
| Логи | видны в панели без настройки |
| Откат | можно вернуть предыдущую версию одной кнопкой или командой |
| Регион | серверы ближе к клиентам |
| Выход | данные и код можно забрать без привязки к сервису |

Предложи два варианта, лучших по этой таблице, и опиши каждый 3–4 строками: сколько стоит, что проще, где данные, что будет, если вырастем.

## Шаг 3. Записать

В `07-ship.md`: выбранный вариант, отвергнутый вариант и почему, дата проверки условий.

## Типовые связки по типу проекта

| Тип | Связка |
|---|---|
| Статическая страница теста | статический хостинг или конструктор страниц + форма + счётчик аналитики |
| Веб-приложение для теста | платформа приложений с деплоем из git + управляемая база той же платформы |
| Бот | платформа приложений с постоянным процессом или вебхуком; база — управляемая или таблица |
| Нужен полный контроль | виртуальный сервер — только для опытного пользователя, потому что бэкапы, обновления и защиту придётся настраивать самому |
