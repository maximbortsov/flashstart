# Тексты на языке Job

Текст для теста не придумывают с нуля — его собирают из того, что уже лежит в `01-frame.md`. Каждая фраза должна опираться хотя бы на один «кирпич» и не обещать больше, чем пользователь сможет дать.

## Кирпичи из frame

| Кирпич | Откуда | Пример |
|---|---|---|
| **Момент** — когда задача возникает | первый шаг цепочки | «Клиент отменил запись за час до визита» |
| **Цель** — ради чего человек всё это делает | Big Job (J2) | «чтобы день мастера был заполнен» |
| **Дело** — что продукт делает за клиента | Core Job (J1) + механика | «сами напоминаем и предлагаем окно другим клиентам» |
| **Мерка** — число из критерия успеха | SC | «свободное окно заполняется за 20 минут» |
| **Сейчас** — чем неудобно текущее решение | разрыв в цепочке | «вместо того чтобы обзванивать базу вручную» |
| **Первый шаг** — что сделать прямо сейчас и сколько это стоит | механика + тест | «пришлите расписание на неделю — настроим бесплатно» |

## Сборки по месту

| Место | Сборка | Пример |
|---|---|---|
| Заголовок | Дело + Мерка | «Заполняем отменённые записи за 20 минут» |
| Заголовок, вариант Б | Момент + Дело | «Клиент отменил запись? Мы найдём замену, пока вы работаете» |
| Подзаголовок | Сейчас → Цель | «Без обзвона базы — и день мастера остаётся полным» |
| Первое сообщение | Момент (вопрос о прошлом) + Дело + Первый шаг | «Как часто у вас отменяют записи в последний момент? Мы тестируем сервис, который сам предлагает окно другим клиентам. Можно настроить для вас бесплатно на неделю — интересно?» |
| Призыв к действию | Первый шаг глаголом | «Прислать расписание», «Забронировать созвон на 15 минут» |
| Ответ на возражение | Мерка или гарантия + что остаётся у клиента | «Если за неделю не заполним ни одного окна — просто отключим, ничего не платите» |
| Письмо после разговора | Цель + Мерка + Первый шаг с датой | «Как договорились: до пятницы настроим напоминания, цель — ни одного пустого окна за неделю» |

Сборки — подсказки, а не закон. Любую фразу можно разобрать обратно на кирпичи; если не разбирается — фраза пустая.

## Чек-лист текста

- [ ] Есть хотя бы одно число из критерия успеха или конкретный срок.
- [ ] Нет прилагательных без доказательства: «удобный», «умный», «лучший», «революционный».
- [ ] Говорим о результате клиента, а не о функциях. Функции — только как доказательство: «как мы это делаем».
- [ ] Слова — из речи клиента (из разговоров, отзывов, чатов), а не из презентации команды.
- [ ] Один призыв к действию, и он дешёвый: не «купить годовую подписку», а «попробовать неделю».
- [ ] Обещание выполнимо в рамках теста. Если результат делаем руками — справимся ли с 20 откликами?
- [ ] Текст понятен человеку, который не знает продукт, за 5 секунд.
- [ ] На языке аудитории из frame; цены и единицы — местные.

## Частые ошибки

| Ошибка | Пример | Как исправить |
|---|---|---|
| Описываем продукт, а не изменение у клиента | «Платформа с ИИ для управления записями» | «Заполняем отменённые записи за 20 минут» |
| Обещаем больше, чем даём | «Никаких пустых окон» | «Заполняем большинство окон за 20 минут — считаем вместе в течение недели» |
| Сразу просим много | «Оформите подписку» | «Пришлите расписание — настроим бесплатно» |
| Вопрос о будущем | «Стали бы вы пользоваться?» | «Как вы решали это в прошлый раз?» |
