# Антипаттерны интерфейса

Список сгруппирован по тому, **чем это вредит клиенту**. Бриф может осознанно разрешить любой пункт, кроме группы «Нельзя прочитать», — тогда исключение с причиной записывается в `DESIGN.md` (Do's and Don'ts).

## 1. Нельзя прочитать — человек не получает информацию

| Признак | Что вместо |
|---|---|
| Текст бледнее 4.5:1 к фону (крупный — 3:1) | поднять контраст; проверять на реальном фоне, включая картинки |
| Серый текст на цветной плашке | оттенок того же цвета или цвет основного текста |
| Основной текст мельче 16 px, подписи и кнопки мельче 14 px | базовый размер 16 px; мелкое — только для вторичных пометок |
| Строка длиннее ~75 знаков или короче ~40 | ширина колонки по тексту, а не по экрану |
| Межстрочный интервал меньше 1.3 у основного текста | 1.4–1.6 для текста, плотнее — только для заголовков |
| Выравнивание по ширине, сплошные заглавные в абзацах | по левому краю; заглавные — только для коротких меток |
| Слишком сжатый или разреженный трекинг | естественный трекинг шрифта; сжатие — только у крупных заголовков и умеренно |
| Текст обрезается, налезает, уходит за край экрана | перенос, многоточие с полным текстом по наведению, проверка на длинных данных |
| Текст прижат к краю экрана на телефоне | поля 16 px и больше |
| Контент скрыт до анимации и может не появиться | виден по умолчанию; анимация только украшает появление |
| Текст поверх картинки без подложки | подложка или затемнение, проверка контраста |

## 2. Шум вместо смысла — внимание уходит на украшения

| Признак | Что вместо |
|---|---|
| Градиент в тексте заголовка | акцент размером, жирностью или одним цветом |
| Свечения, ореолы, радиальные «прожекторы» за блоками | спокойный фон; глубина — тенью со смещением и мягким размытием |
| Стекло и размытие как украшение | только там, где под панелью реально есть контент |
| Цветная полоса сбоку у карточек, плашек, уведомлений | иконка состояния или цвет фона всей плашки |
| Пульсирующие точки, бегущие строки, мигающий курсор | статичный индикатор состояния |
| Полосы и сетка на фоне без смысла | фон-поверхность; сетка — только если это реально чертёж, карта, график |
| «Пружинящие» анимации | короткое плавное замедление в конце |
| Ряд одинаковых карточек «иконка в квадрате + заголовок + текст» | структура по смыслу: список, таблица, сравнение, один главный блок |
| Карточка внутри карточки | одна поверхность и разделители |
| Надпись-«чип» над каждым заголовком, номера разделов 01/02/03 | заголовок без надстроек; номера — только если важен порядок |
| Шаблон «огромная цифра + маленькая подпись» без нужды | число в контексте фразы или таблицы |

## 3. Шаблонный вид — продукт неотличим от сотни других

| Признак | Что вместо |
|---|---|
| Самые заезженные шрифты «по умолчанию» для всего | шрифт под голос продукта из `PRODUCT.md`; системный — осознанно, для режима «работать» |
| Фиолетово-синие градиенты, «кремовая» палитра просто так | палитра из обстановки и голоса продукта |
| Курсивный антиквенный заголовок как универсальный «премиум» | начертание по характеру продукта |
| Гигантский первый заголовок на полэкрана | заголовок, после которого виден следующий смысловой блок |
| Моноширинный шрифт для «технологичности» | моноширинный — только для кода, чисел, измерений |
| Эмодзи и символы вместо иконок | одна библиотека иконок или свои SVG в одном стиле |
| Тёмная тема, «потому что так у всех в категории» | тема по обстановке использования |
| Иллюстрация, собранная из кругов и прямоугольников | настоящая иллюстрация или фото, либо без картинки |

## 4. Сломанная структура — непонятно, что главное

| Признак | Что вместо |
|---|---|
| Пропущенные уровни заголовков (h1 → h3) | последовательные уровни |
| Все заголовки почти одного размера | заметный шаг размера и жирности между уровнями |
| Одинаковые отступы везде | плотно внутри группы, просторно между группами; над заголовком больше, чем под ним |
| Тесные внутренние поля у кнопок и карточек | поля по шкале `spacing` из `DESIGN.md` |
| Карточки вплотную к краям экрана | внешние поля по шкале |
| Модальное окно там, где хватит строки или панели | модалка — только когда нужно остановить и сфокусировать |
| Кнопки и ссылки меньше 44×44 px на касание | зона нажатия не меньше 44 px |

## 5. Пустые слова — текст ничего не говорит

| Признак | Что вместо |
|---|---|
| «Революционный», «инновационный», «бесшовный», «на базе ИИ» | что именно меняется у клиента и на сколько |
| Театральные фразы и афоризмы ради ритма | простое утверждение с числом |
| Тире через каждое предложение | обычная пунктуация |
| Одна и та же фраза в нескольких блоках | каждый блок говорит своё |
| Выдуманные отзывы, логотипы, награды | только реальные доказательства или ничего |

## 6. Дрейф от системы — каждый экран чуть другой

| Признак | Что вместо |
|---|---|
| Цвет, шрифт, размер, радиус не из `DESIGN.md` | токен из `DESIGN.md` или осознанное добавление в него |
| Стили, вписанные прямо в элементы | классы и переменные проекта |
| Разные компоненты для одного и того же действия | один компонент из `Components` |

## 7. Просто сломано

| Признак | Что вместо |
|---|---|
| Битые картинки, ошибки скриптов в консоли | исправить до показа |
| Горизонтальная прокрутка на телефоне | проверить ширину 375 px |
| Важная картинка ушла вглубь страницы без причины | главное — на первом экране |
