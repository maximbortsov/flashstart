# Выбор стека

> **Статус пресета starter — черновик.** Его окончательный состав определяется на эталонном прогоне `examples/h-001` (FRAMEWORK §9, открытое решение). До этого используй критерии ниже и помечай выбор в `05-architecture.md` как предварительный.

## Критерии выбора (по порядку важности)

1. **Есть ли уже код.** Есть — продолжаем на нём, если нет серьёзной причины менять. Смена стека — отдельное решение (ADR).
2. **Уровень пользователя.** Новичку — один язык на всё, минимум настройки, хостинг без администрирования серверов, понятные сообщения об ошибках.
3. **Тип продукта.**
   | Тип | Обычно достаточно |
   |---|---|
   | Страница для теста (лендинг, форма) | статический сайт или конструктор страниц + форма + счётчик аналитики |
   | Веб-приложение | один фулстек-фреймворк + одна база данных + вход по email-ссылке или через внешний сервис |
   | Бот в мессенджере | один язык + библиотека бота + база данных или таблица |
   | Мобильное приложение | сначала проверить, не хватит ли веб-приложения для телефона; нативное — только если без него не дойти до Aha |
4. **Рынок.** Хостинг, платежи и почта должны работать в стране пользователя и принимать его способ оплаты. Окончательный выбор хостинга — в `fs-ship`, но стек не должен его исключать.
5. **Аналитика.** Выбранный стек должен позволять отправить события из `04-spec.md` без отдельного бэкенда для аналитики.

## Пресет starter (черновик)

Принципы, которым должен соответствовать любой кандидат в пресет:

- **Один язык** на клиенте и сервере.
- **Один репозиторий**, одна команда для локального запуска, одна — для тестов.
- **База данных без администрирования**: файл на диске для прототипа или управляемая база у хостинга.
- **Вход без своих паролей**: ссылка на email или внешний провайдер.
- **Деплой по `git push`** или одной командой.
- **Тесты из коробки**: фреймворк тестов уже настроен.
- **Популярность**: по стеку много примеров и ответов, агент хорошо его знает.

Кандидат для веб-приложения (проверить на h-001): TypeScript, один фулстек-фреймворк с серверными маршрутами, SQLite для прототипа с переходом на управляемый Postgres, встроенный тест-раннер фреймворка, хостинг с деплоем из git.

## Когда стек свой

Запиши, что выбрал пользователь, и проверь по критериям 2–5. Если критерий нарушен — скажи, чем это грозит, одной фразой, и оставь выбор пользователю. Свой стек опытного пользователя важнее пресета.

## Хорошее архитектурное решение (пример формы)

**ADR-2: Вход по ссылке на email**
- Контекст: мастеру нужно входить с телефона и компьютера; пароли — лишний шаг до Aha.
- Решение: вход по одноразовой ссылке на email через сервис рассылки.
- Отвергнуто: пароли (лишний шаг, восстановление), вход через соцсети (не у всех мастеров есть аккаунты, зависимость от платформы).
- Последствия: нужен сервис отправки писем и шаблон письма; без почты войти нельзя — это граничный случай в spec.
