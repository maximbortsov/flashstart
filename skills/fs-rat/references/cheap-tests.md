# Дешёвые тесты — от риска к способу проверки

Выбирай тест по тому, **какой вопрос** он должен закрыть. Внутри строки — от дешёвого к дорогому. Бери первый, который даст число для kill-порога.

| Вопрос из допущения | Тест | Что считаем | Обычная стоимость |
|---|---|---|---|
| **Есть ли такие люди?** | Поиск в местах, где они собираются: чаты, форумы, отзывы на текущие решения | сколько людей пишут о задаче своими словами | часы |
| | Холодные сообщения 20–30 людям из сегмента с просьбой о 15-минутном разговоре | доля согласившихся | 1–3 дня |
| | Разговоры о прошлом опыте: «расскажите, как вы в последний раз решали …» | у скольких из N задача была за последний месяц и чем решали | 3–7 дней |
| **Захотят ли они это?** | Предложение в переписке: описание результата + цена + «готовы попробовать?» | доля «да» с конкретным следующим шагом | 1–3 дня |
| | Предоплата или предзаказ | число оплат | 3–7 дней |
| | Лендинг с одной кнопкой заявки или оплаты + небольшой трафик | конверсия в заявку при известном источнике трафика | 3–10 дней, бюджет на рекламу |
| | Демо-видео или кликабельный макет на созвоне | сколько попросили доступ или назначили следующий шаг | 3–7 дней |
| **Сможем ли мы это дать?** | Сделать результат руками для 3–5 клиентов | доля случаев, где уложились в критерии успеха | 1–2 недели |
| | Собрать из готовых сервисов (таблица, форма, бот-конструктор) | время и ошибки на одного клиента | дни |
| **Дойдём ли до них?** | Пост или сообщение в одном канале с понятной аудиторией | отклики на 1 000 показов | часы–дни |
| | Маленькая рекламная кампания на лендинг | цена заявки | бюджет + 3–7 дней |
| **Сойдётся ли в деньгах?** | Посчитать себестоимость ручной работы на первых клиентах | маржа на клиента | по ходу ручного теста |
| | Спросить о текущих тратах на задачу: деньги и время | сколько платят сейчас | в тех же разговорах |
| **Риск этого продукта** (партнёр, исполнитель, платформа, регулятор) | Позвонить тому, от кого зависит результат: партнёру, исполнителю, юристу, человеку, который уже пытался сделать похожее | готовность, условия, запреты | часы–дни |

## Правила хорошего теста

- **Один тест — одно главное допущение.** Если тест закрывает два — назови оба, но порог ставь по главному.
- **Поведение важнее слов.** «Звучит интересно» — не результат. Результат — заявка, оплата, назначенная встреча, потраченное время.
- **Спрашивай о прошлом, не о будущем.** «Как вы решали это в прошлый раз?» надёжнее, чем «стали бы вы пользоваться?».
- **Знакомые не считаются** — они соглашаются из вежливости. Хотя бы половина выборки — незнакомые люди из сегмента.
- **Порог — до теста.** Число и дата пишутся в `02-rat.md` до первого сообщения.
- **Ручная работа — не стыдно.** Сделать за клиента руками — самый быстрый способ узнать, сможем ли мы дать результат и сколько он стоит.
