# Обкатка FlashStart — памятка участнику

Спасибо, что участвуете. Мы проверяем, помогает ли FlashStart раньше и дешевле узнавать правду о продуктовой идее, чем обычная разработка с ИИ. Проверяем **фреймворк**, а не вас и не ваши идеи: закрытая идея — такой же полезный результат, как успешная.

## Что нужно от вас

1. **Две идеи**, по которым ещё ничего не сделано: ни кода, ни разговоров с клиентами.
2. **Жребий:** бросьте монетку — орёл: идея 1 идёт через FlashStart (FS), решка: идея 2. Вторая идея (К) ведётся как вы обычно работаете, с любым ИИ.
3. **Две папки или два репозитория.** FlashStart ставите только в папку идеи FS:
   ```bash
   git clone https://github.com/maximbortsov/flashstart.git ~/.flashstart
   cd путь/к/идее-FS && python3 ~/.flashstart/install.py
   ```
   Дальше в Claude Code: `/fs-frame`, а потом `/fs` подскажет следующий шаг.
4. **~5 часов в неделю на каждую идею, 4 недели.**
5. **Журнал** — файл `flashstart-trial-journal.xlsx`, одна строка после каждой рабочей сессии. Инструкция — на первом листе.
6. **Неделя 5:** анкета (последний лист журнала) и разговор на 30 минут.

## Правила

- Пишите в журнал сразу после сессии, а не в конце недели по памяти.
- Если скилл FlashStart непонятен, ошибается или мешает — строка на листе «Трения FS». Это самое ценное, что вы можете нам дать.
- Ведущий помогает только с установкой и ошибками. Как применять метод — решайте сами, иначе мы проверим ведущего, а не фреймворк.
- Если привычки из FlashStart просачиваются в идею К — это нормально, просто расскажите об этом в анкете.
- Отвечайте честно: «мешало» — полезный ответ.
