# Контракт артефактов — формат для `trace-check`

Дополняет FRAMEWORK.md §5. Источник правды для машинной проверки — frontmatter; текст тела вторичен (кроме маркеров AC).

## 1. Где лежат файлы

```
<продуктовый репо>/
├─ PRODUCT.md                    # один на продукт, совместим с Impeccable
├─ DESIGN.md                     # один на продукт, спецификация DESIGN.md
├─ .fs/state.yaml                # состояние текущей гипотезы
└─ docs/fs/h-001/
   ├─ 01-frame.md   02-rat.md   03-test.md   04-spec.md
   ├─ 05-architecture.md   06-learn.md   07-ship.md
   ├─ project-context.md
   ├─ review.md
   └─ stories/
      ├─ E1.md                   # эпик
      └─ S1.1.md                 # история
```

`trace-check` читает `*.md` в папке гипотезы и в `stories/`. Файлы без frontmatter или без ключа `fs` пропускаются.

## 2. Frontmatter

| Ключ | Обязателен | Что это |
|---|---|---|
| `fs` | да | тип: `frame`, `rat`, `test`, `spec`, `architecture`, `epic`, `story`, `learn`, `ship` |
| `hypothesis` | да | `h-NNN`; должен совпадать с именем папки (иначе предупреждение I6) |
| `upstream` | нет | файлы, из которых выведен артефакт |
| `ids` | да, если артефакт рождает ID | список ID, **объявленных** в этом файле |
| `refs` | нет | `{ID: [ID, …]}` — исходящие ссылки ID этого файла |
| `items` | нет | `{ID: {свойство: значение}}` — свойства ID этого файла |
| `status` | нет | статус документа: `draft`, `approved`, `superseded` |

Специфичные ключи: `track` (в `02-rat.md`), `market`, `audience_language` (в `01-frame.md`), `tests`, `decision_date` (в `03-test.md`), `decision` (в `06-learn.md`), `user_level`, `stack_preset` (в `05-architecture.md`).

## 3. Свойства в `items`

| ID | Свойства |
|---|---|
| `J` | `level`: `core` / `big`; `confidence`: `head` / `interview` / `data` |
| `SC` | `confidence`; `measure` — способ измерения (обязателен для гейта frame, иначе G1) |
| `A` | `status`: `open` (по умолчанию) / `confirmed` / `refuted` / `dropped`; `p`, `impact`, `cost` — 1–5; `test`; `kill` |
| `FR` | `priority`: `must` / `should` |
| `EV` | `name` — имя события в аналитике |
| `E` | `aha: true` — у эпика Aha Moment |
| `S` | `status`: `todo` / `planned` / `in-progress` / `review` / `done`; `ui: true` для UI-историй |

Любой ID со `status: dropped` или `superseded` выводится из проверок; номер не переиспользуется.

## 4. Допустимые ссылки

| Кто ссылается | На кого |
|---|---|
| `SC` | `J` (обычно не нужно: родитель задан номером `SC1.x → J1`) |
| `A` | `J`, `SC` |
| `FR` | `SC` |
| `EV` | `SC` |
| `E` | `FR` |
| `S` | `FR`, `EV` |

Принадлежность задаётся номером: `SC2.1` → `J2`, `S1.3` → `E1`.

## 5. Критерии приёмки

Каждый AC в теле истории помечается `AC1`, `AC2`, … — независимо от языка: `- **AC1** Дано …, когда …, тогда …`.

## 6. Правила и коды

| Код | Уровень | Правило |
|---|---|---|
| R1 | ошибка | каждый FR ссылается хотя бы на один SC |
| R2 | ошибка | каждый SC, на который ссылаются FR, измеряется хотя бы одним EV |
| R3 | ошибка | каждая история ссылается на FR и содержит хотя бы один AC |
| R4 | ошибка | в треках M/L, когда ожидаются эпики: эпик с `aha: true` есть и он первый по номеру |
| R5 | ошибка | у каждого открытого A есть `test` и `kill` |
| R7 | ошибка | когда ожидаются истории: каждый FR покрыт историей |
| I0–I5 | ошибка | разбор frontmatter, дубли ID, висячие ссылки, формат ID, сирота без родителя, недопустимый тип ссылки |
| G1 | предупр. | у SC нет `measure` |
| W1 | предупр. | spec опирается на Job с `confidence: head` |
| I6, I7 | предупр. | `hypothesis` не совпадает с папкой; ссылка на выведенный из работы ID |

**Когда ожидаются эпики и истории:** трек M — после появления `04-spec.md`; трек L — после появления `05-architecture.md`; трек S — никогда.

**Трек** берётся из `track` в `02-rat.md`, иначе из `.fs/state.yaml`.

## 7. Validation debt

`total = открытые A + пропущенные гейты (skipped_gates в .fs/state.yaml) + 1, если spec опирается на [head]-Job`. Выводится с разбивкой.

## 8. Запуск

```
python3 scripts/trace-check.py [docs/fs | docs/fs/h-001 ...] [--json] [--state .fs/state.yaml] [--builtin-yaml]
```

Код выхода: 0 — зелёный, 1 — есть ошибки, 2 — гипотез не найдено. Нужен только Python 3.10+; PyYAML используется, если установлен.
