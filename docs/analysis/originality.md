# Проверка оригинальности

Дата: 2026-10-16. Метод — ручная сверка (решение автора): каждый файл FlashStart с высоким риском заимствования сравнён с соответствующей частью источника по трём признакам: **состав** пунктов, **порядок**, **формулировки** (включая близкий перевод). Дословная проверка n-граммами (≥ 8 слов) на всех файлах — 0 совпадений, кроме обязательных ключей формата в `examples/h-001/DESIGN.md`; для пары «русский текст — английский источник» она почти ничего не доказывает, поэтому основной метод — ручной.

Версии источников — `docs/inspiration.md`.
