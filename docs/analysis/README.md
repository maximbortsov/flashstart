# Анализ источников — сводка расхождений с FRAMEWORK.md

Конспекты: [nmt.md](nmt.md) · [bmad.md](bmad.md) · [impeccable.md](impeccable.md). Спецификация не правилась; ниже — решения, которые нужны от автора.

| # | Расхождение | Где в FRAMEWORK | Предложение |
|---|---|---|---|
| 1 | NMT под CC BY-NC-SA 4.0: перенос каталога механик и формул текстов близок к адаптации; для публичного (тем более платного) продукта — риск | §2 NMT «Берём» | Брать идею каталога/формул, содержимое и состав — свои. Юрист перед релизом. |
| 2 | Ранжирование допущений «риск × неопределённость» не учитывает стоимость проверки | §4 `fs-rat` | `(вероятность ошибки × ущерб) / стоимость проверки`, шкалы 1–5 |
| 3 | «Critical Chain of Jobs» — фирменный термин NMT, а политика запрещает чужие фирменные названия в артефактах | §2, §4 `fs-frame`, `fs-spec` | «цепочка шагов» (`chain`) |
| 4 | BMAD описан в терминах v6 (story-файл, dev-story, project-context.md, sprint); в V7 их заменили spec-ядро, ticket, build | §2 BMAD, §4 `fs-plan` | Истории коротко в `fs-plan`, план и задачи дописывает `fs-build` |
| 5 | `project-context.md` со стеком и структурой, по данным, на которые ссылается BMAD, не помогает агенту и дорожает на ~20% | §4 `fs-plan` | Только неочевидные правила; либо блок в `CLAUDE.md` продуктового репо |
| 6 | `PRODUCT.md`/`DESIGN.md` Impeccable ищет в корне проекта, FRAMEWORK кладёт артефакты в `docs/fs/h-NNN/` | §4 `fs-spec`, `fs-design`; §7 | Писать `PRODUCT.md` и `DESIGN.md` в корень продукта, гипотезу — в frontmatter |
| 7 | «Свой чек-лист вместо детектора» — это разные уровни (смысл vs CSS) | §2 Impeccable | «Свой смысловой чек-лист; детектор — опционально» |
| 8 | `_sources/VERSIONS.md` в игнорируемой папке → hash не версионируются | KICKOFF §1 | Hash продублированы в `docs/inspiration.md` (сделано) |
| 9 | BMAD V7 в альфе, релиз 2026-10-16 | KICKOFF §1 | Перепроверить сводку по новому hash после релиза |

## Идеи-кандидаты, которых нет в FRAMEWORK

| Идея | Источник | Куда |
|---|---|---|
| Конкретность допущения: названы сегмент, объём/цена, канал, срок | NMT | гейт `fs-rat` |
| «Что выкинуть»: убрать риск целиком (ручная работа вместо интеграции) | NMT | выбор трека в `fs-rat` |
| Метка утверждений: подтверждено / выведено / предположение | NMT | все артефакты |
| Вопрос о рынке и языке аудитории в начале | NMT | `fs-frame` |
| Kill-порог «все участники UX-теста проходят Core Job» | NMT | `fs-learn` (M/L) |
| Обещание ≤ поставки в текстах | NMT | `fs-test`, `fs-design` |
| Объём истории = одна цель, одна сессия (~500 строк) | BMAD | `fs-plan` |
| AC в форме «дано / когда / тогда»; никаких TBD в плане | BMAD | `fs-plan`, `fs-build` |
| Линза ревью «граничные случаи» вдобавок к состязательной | BMAD | `fs-build` |
| Триаж: своё чинить, чужое — в `deferred.md`, ошибка цели — назад в spec | BMAD | `fs-build` |
| Режим поверхности: убедить / работать / читать | Impeccable | бриф экрана в `fs-design` |
| Не больше 2 раундов визуальной проверки | Impeccable | `fs-design` |
| Скриншоты в двух ширинах, реальный контент вместо заглушек | Impeccable | `fs-design` |
